## Як запустити

Сервіс уже працює як служба на сервері й піднімається сам після перезавантаження:

```bash
systemctl --user status club-api      # стан
systemctl --user restart club-api     # перезапустити після зміни коду
journalctl --user -u club-api -n 30   # останні рядки логу, якщо щось не так
```

Перевірити, що відповідає:

```bash
curl http://127.0.0.1:9511/api/ping
```
